マイクロハーブ 注文票の自動印刷（カフェのSurface用）

【はじめに設定するとき】
1. このフォルダを「すべて展開」してから開きます（ZIPのまま開かないでください）
2. 「setup.bat」をダブルクリックします
   - 「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」
   - 「このアプリがデバイスに変更を加えることを許可しますか？」は「はい」
3. 画面の案内にそって進めます
   - テスト印刷が出たかどうかを答えます
   - 管理画面のパスワードを入力します
4. 「設定が終わりました！」と出たら完了です

【ふだん】
- Surfaceは電源につないで、開いたままにしておいてください
- 7:00〜20:00の間、1分ごとに新しい注文・キャンセルを確認して印刷します
- 動いているかは、管理画面の「その他」→「システムの状態」で確認できます

【音を鳴らすとき】
- 「beep-test.bat」をダブルクリックして、音が鳴ったか答えます（紙は出ません）
- 新規注文は1回、キャンセルは2回鳴ります

【やめるとき】
- 「uninstall.bat」をダブルクリックします

【困ったとき】
- 記録は C:\ProgramData\MicroherbPrint\print.log にあります
